🧪 TESTS AFFIXES

Pour chaque affixe du catalogue, simule un combat avec / sans l'affixe et compare les résultats. Si une différence mesurable est observée → ✅ MARCHE. Sinon → ❌ IGNORÉ. Les tests sont stochastiques (basés sur RNG), donc on lance N itérations pour stabiliser.

Légende :
✅ OK — l'affixe a un effet mesurable en combat (la stat sort dans player.X et le moteur la lit)
⚠️ PARTIEL — la stat arrive bien dans player.X mais le moteur ne semble pas la consommer
❌ IGNORÉ — l'affixe n'arrive même pas dans player.X (pas dans STAT_MAP de equipment-builder)

Note : certains tests sont approximatifs (statistique sur N itérations) — utiliser plusieurs runs pour confirmer.
